## How to use this file

**A snapshot of what is true NOW. Not a log.** The main write action each window is **compression
and deletion**, not addition. Test every line: **does this change today's judgement?** If not, cut —
interesting and might-matter-later are not reasons to keep. Cutting is **demotion, not loss**: every
window's full text stays in `content/finance/windows/**`, which is what makes ruthlessness safe.
Never stack yesterday's narrative beside today's. Hard cap **3,000 words** — a net, not a target.
